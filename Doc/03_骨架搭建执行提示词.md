````markdown
## 五、 固定接口签名（实现期唯一依据，禁止各写一套）

以下签名直接落实进 `src/AIFramework.Contracts`，实现方、装配方与测试方一律以此为准。

### 5.1 总线（`ICqeBus`）

```csharp
public interface ICqeBus
{
    void Send<TCommand>(in TCommand command) where TCommand : struct, ICommand;
    TResult Query<TQuery, TResult>(in TQuery query) where TQuery : struct, IQuery<TResult>;
    void Publish<TEvent>(in TEvent evt) where TEvent : struct, IEvent;

    void RegisterCommandHandler<TCommand>(ICommandHandler<TCommand> handler)
        where TCommand : struct, ICommand;

    void RegisterQueryHandler<TQuery, TResult>(IQueryHandler<TQuery, TResult> handler)
        where TQuery : struct, IQuery<TResult>;

    void Subscribe<TEvent>(IEventHandler<TEvent> handler)
        where TEvent : struct, IEvent;
}
```

> 纪律：`BattleWorld.Step()` 与 `Kernel.Turn` 的推演帧内禁止调用 `ICqeBus`，跨边界只写 `IIntentWriter`。该约束由 `AIFramework.Core.Tests` 的 1000 帧 0 B 断言兜住。

### 5.2 会话进出门（`IGameplaySession` / `IGameplayKernelFactory`）

```csharp
public interface IGameplaySession
{
    void Step(float deltaSeconds);
    bool IsFinished { get; }
    GameplayResult CollectResult();
}

public interface IGameplayKernelFactory
{
    IGameplaySession Create(GameplayKernelType type, in GameplayInitData init);
}
```

> `GameplayResult` 定为 `sealed class`（内部可含数组），**只允许在 `CollectResult()` 内构造一次**：`Step()` 内禁止构造、禁止刷新它，也禁止把只读视图直接塞进去当字段；`IsFinished == false` 时或第二次调用 `CollectResult()` 必须抛 `InvalidOperationException`，成功调用一次即交还会话所有权。`IGameplayKernelFactory` 的唯一实现方是装配层（`ConsoleAppBootstrap` / `UnityBootstrapper`），`Core` 与 `Features` 都不得实现。

### 5.3 空间查询（`ISpatialQuery`）

```csharp
public interface ISpatialQuery
{
    int QueryCircle(in Vec2 center, float radius, Span<UnitHandle> results);
    int QueryProjectilesCircle(in Vec2 center, float radius, Span<ProjectileHandle> results);
}
```

> 返回值为实际写入数量；`results` 容量不足时按容量截断，不抛异常、不扩容。

### 5.4 配置加载（`IBinaryTableLoader`）与 Phase 1 最小 Mock 格式

```csharp
public interface IBinaryTableLoader
{

### 5.5 帧内写入通道与技能阶段（FrameData 驱动，零分配）

```csharp
public interface IIntentWriter
{
    void Submit(in ControlIntent intent);
    void Submit(in MoveIntent intent);
    void Submit(in DamageIntent intent);
    void Submit(in ReflectProjectileIntent intent);
}

public readonly struct PhaseContext
{
    public readonly int FrameId;
    public readonly UnitReadView Owner;
    public readonly IUnitWorldReadView World;
    public readonly IProjectileWorldReadView Projectiles;
    public readonly ISpatialQuery Spatial;

    public PhaseContext(int frameId, in UnitReadView owner,
                        IUnitWorldReadView world, IProjectileWorldReadView projectiles,
                        ISpatialQuery spatial)
    {
        FrameId = frameId;
        Owner = owner;
        World = world;
        Projectiles = projectiles;
        Spatial = spatial;
    }
}

public interface ISkillInteractionPhase
{
    void Execute(in PhaseContext context, IIntentWriter writer);
}

public interface IUnitWorldReadView
{
    bool TryGetUnit(UnitHandle handle, out UnitReadView view);
}

public interface IProjectileWorldReadView
{
    bool TryGetProjectile(ProjectileHandle handle, out ProjectileReadView view);
}
```

> 三条硬约束：
> 1. **意图提交必须是四个显式重载，不得写成泛型 `Submit<TIntent>(in TIntent)`**：泛型版本会迫使内核再做一次类型分发，而意图类型是编译期固定闭集，显式重载最简单且零分配。
> 2. 每类意图在内核侧配一条预分配定长缓冲；**缓冲满时丢弃该意图并在诊断缓冲记一个溢出码，禁止扩容、禁止抛异常**（帧内抛异常会破坏确定性与逐帧一致性）。
> 3. 只读视图接口只允许 `out` / 值类型返回，**禁止返回数组、`List<T>`、`IEnumerable<T>`**，否则遍历即分配。
````
