# 玩法卡带索引（当前仓库实际可运行的东西）

> 一句话：**一套 Contracts + 两套内核（Turn / Realtime）+ 一个 Meta 切片聚合包 + 十六个玩法场景**。
> 所有玩法共用同一个 CQE 总线、红点、背包、存档与因果日志；新增玩法 = 新增内核内容或新增 Meta 切片，不动其它模块。

---

## 一、五个内核内容（`Kernel.Turn` / `Kernel.Realtime`）

| 内容 | 程序集 | 输入端口 | 读视图 | 玩法要点 | 无头测试 |
|---|---|---|---|---|---|
| 卡牌战斗 `CardBattleWorld` | Kernel.Turn | `ICardBattleInput`（出牌/结束回合） | `ICardBattleReadView` | 5 张手牌、3 点能量、30 回合上限、敌方 HP=max(10, 单位数×10) | `CardBattleWorldTests` |
| 三消 `Match3World` | Kernel.Turn | `IMatch3Input`（交换） | `IMatch3ReadView` | 8×8、5 色、20 步、1000 分目标、连消计深 | `Match3WorldTests` |
| 战棋 `TacticsWorld` | Kernel.Turn | `ITacticsInput`（选/移/攻/结束回合） | `ITacticsReadView` | 8×8、BFS 可达、敌方 AI、50 回合平局 | `TacticsWorldTests` |
| 推箱子 `PuzzleWorld` | Kernel.Turn | `IPuzzleInput`（四方向/重置） | `IPuzzleReadView` | 3 个内置关卡、推箱判定、解出即胜 | `PuzzleTests` |
| 俄罗斯方块 `TetrisWorld` | Kernel.Turn | `ITetrisInput`（左/右/转/软降/硬降/Tick） | `ITetrisReadView` | 7-bag、踢墙、消行计分、等级加速 | `TetrisTests` |
| 自走棋 `AutoChessWorld` | Kernel.Turn | `IAutoChessInput`（放置/挪位/出售/开战/结算） | `IAutoChessReadView` | 8×8 半场、确定性自动运行 30 tick、血量结算 | `AutoChessTests` |
| 跑酷 `RunnerWorld` | Kernel.Turn | `IRunnerInput`（跳/蹲/Tick） | `IRunnerReadView` | 自动前进、Low 跳/High 蹲、障碍回收、距离计分 | `RunnerTests` |
| 音游 `RhythmWorld` | Kernel.Turn | `IRhythmInput`（Tick/按轨打点） | `IRhythmReadView` | 4 轨、四档判定窗、连击/准确率、AutoPlay 自动完美 | `RhythmTests` |
| 平台跳跃 `PlatformerWorld` | Kernel.Turn | `IPlatformerInput`（左右/跳/Tick） | `IPlatformerReadView` | 重力/单向平台/收集品/终点，子步切分防穿墙 | `PlatformerTests` |
| 肉鸽卡牌 `RoguelikeWorld` | Kernel.Turn | `IRoguelikeInput`（前进/出牌/结束回合） | `IRoguelikeReadView` | 8 层地图、卡组/抽弃/手牌、商店/营地/Boss、种子可复现 | `RoguelikeTests` |
| 黑白棋 `BoardGameWorld` | Kernel.Turn | `IBoardGameInput`（落子/AI/重开） | `IBoardGameReadView` | 8×8 翻转规则、自动跳过、Easy/Normal/Hard（4 层 minimax + 角点权重） | `BoardGameTests` |
| 实时战场 `BattleWorld` | Kernel.Realtime | `IIntentWriter`（移动/伤害/反射） | `IUnitWorldReadView` / `IProjectileWorldReadView` | 6 阶段固定帧管线、护盾反射、零分配 | `BattleWorldTests` |

**为什么都能塞进两套内核**：内核只承诺"会话生命周期 + 固定步进 + 只读视图 + 输入端口"，内容决定状态怎么变。新增内容不需要改内核类型，也不需要新的 `GameplayKernelType` 枚举值（战棋/推箱子/俄罗斯方块/自走棋都复用 `Turn`）。

## 二、十四个 Meta 切片（`AIFramework.Features`）

| 切片 | 输入（命令） | 输出（事件/查询） | 要点 |
|---|---|---|---|
| 签到 `DailySignIn` | 领取今天 / 补签 | 状态查询、发奖指令 | 跨天刷新、周期、补签卡 |
| 背包 `Inventory` | 获得 / 消耗 | 数量查询、列表查询 | 唯一账本，其它切片只发指令 |
| 商店 `Shop` | 购买 | 目录查询 | 数量≠1 先拒、扣款后发货 |
| 任务 `Quest` | 进度推进（由 `GameFinishedEvent` 驱动） | 列表查询 | 状态优先级：已领 > 过期 > 未读 |
| 邮件 `Mail` | 领取 / 删除 | 列表查询 | 已领删除静默拒绝、红点播种 |
| 红点 `RedDot`（Core） | 增量/置位命令 | 状态查询 | 数值化节点 ID、读写分离 |
| 放置经营 `IdleTycoon` | 升级建筑 / 结算离线 | 建筑等级、收入/秒 | 24h 封顶、回拨不结算 |
| 抽卡 `Gacha` | 单抽 / 十连 | 最近结果、保底计数 | 权重、10 抽保底、固定种子可复现 |
| 合成 `Merge` | 合成 / 生成 | 网格快照 | 相邻同等级合成、金币查表 |
| 塔防建造 `TowerDefense` | 建造 | 布局查询 | 越界/占位/金币不足静默拒绝 |
| 本地化 `Localization` | 切语言 | key → 文案查询 | 当前语言→默认语言→key 三级回退 |
| 模拟经营 `Tycoon` | 建造/升级/雇员工/结算 tick | 快照查询 | 金币缓存防超支、收入随等级与员工增长 |
| 挂机 RPG `IdleRpg` | 战斗 tick/进关/升级 | 快照查询 | 5 关攀爬、每 3 tick 反击、经验升级 |
| 异步 PVP `AsyncPvp` | 挑战离线对手 | 段位/对手池查询 | 确定性算分、段位与连胜、里程碑发奖 |

**纪律**：切片之间不互相引用（`AIF001` 编译期拦截），跨切片只走 `Contracts` 里的 CQE 契约。

## 三、二十个场景（`unity/Assets/AIFrameworkDemo/Scenes/`）

| 场景 | 演示内容 | 用到的内核/切片 |
|---|---|---|
| `BootScene` | 启动 → 大厅（不建宿主，避免跨场景残留） | — |
| `LobbyScene` | 签到 / 商店 / 任务 / 邮件 / 弹窗队列 / 本地化切换 / 战斗入口 / 十五场景导航 | Meta 全家桶 |
| `CardBattleScene` | 卡牌战斗（出牌、能量、敌方回合） | `CardBattleWorld` |
| `Match3Scene` | 三消（交换、连消、步数、目标分） | `Match3World` |
| `ArenaScene` | 三波竞技场（护盾反射、波次推进、重开） | `BattleWorld` + `RealtimeSceneBinder` |
| `TowerDefenseScene` | 建塔 → 重开一局自动战斗 | `TowerDefense` + `BattleWorld` |
| `IdleScene` | 放置经营（升级、收入/秒） | `IdleTycoon` |
| `GachaScene` | 抽卡（单抽/十连/保底） | `Gacha` |
| `DemoScene` | Realtime 最小演示（胶囊/护盾/反射） | `BattleWorld` |
| `PuzzleScene` | 推箱子（自动解法/重置/下一关） | `PuzzleWorld` |
| `TetrisScene` | 俄罗斯方块（自动下落/消行/重开） | `TetrisWorld` |
| `AutoChessScene` | 自走棋（布阵/开战/下一回合） | `AutoChessWorld` |
| `RhythmScene` | 音游（4 轨判定/连击/自动完美演奏） | `RhythmWorld` |
| `BulletHellScene` | 弹幕射击（Realtime + 碰撞体绑定 + 自动走位） | `BattleWorld` |
| `RunnerScene` | 跑酷（30 列字符跑道 + 自动躲障） | `RunnerWorld` |
| `BoardGameScene` | 黑白棋（字符盘 + 8×8 按钮 + 三档 AI 自动对局） | `BoardGameWorld` |
| `TycoonScene` | 模拟经营（建造/升级/雇员工/结算 tick） | `Tycoon` 切片 |
| `IdleRpgScene` | 挂机 RPG（打 tick/升级/进关） | `IdleRpg` 切片 |
| `PlatformerScene` | 平台跳跃（20×10 简图 + 自动通关） | `PlatformerWorld` |

**场景切换**：Boot → Lobby 单向；Lobby 用 `SceneNavigator` 进任意玩法场景；每个玩法场景都有"返回大厅"。

## 四、怎么验证（五层流水线）

```powershell
dotnet build AIFramework.Pure.sln                                  # 1. 语言层（0 警告 0 错误）
dotnet test AIFramework.Pure.sln                                   # 2. 纯逻辑 605 例
dotnet run --project tools/viewgen -- --all                        # 3. 生成物一致性（6 份）
pwsh unity/tools/check-adapter-compile.ps1                         # 4. 适配层形状（0/0）
pwsh unity/tools/generate-scenes.ps1                               # 5a. 真 Unity 场景生成 + 装配校验
pwsh unity/tools/run-unity-tests.ps1 -TestPlatform EditMode        # 5b. 真机 10 例
pwsh unity/tools/run-unity-tests.ps1 -TestPlatform PlayMode        # 5c. 真机 11 例
```

第 5 层跑在"临时副本工程"里（`robocopy /MIR` 镜像 + 保留 Library 增量导入），不影响正在打开的编辑器。

## 五、再加一个玩法要动哪些文件（清单）

**纯逻辑新玩法（推荐先做这个）**
1. `src/AIFramework.Contracts/Gameplay/Turn/XXXContracts.cs`（读视图 + 输入端口）
2. `src/AIFramework.Kernel.Turn/XXX/XXXWorld.cs`（≤400 行）
3. `tests/AIFramework.Core.Tests/Kernel/XXXTests.cs`（正常路径 + 边界反例 + 零分配）
4. 适配层：`Runtime/Battle/XXXController.cs` + `XXXHud.cs`（读视图驱动 UI，写端口驱动逻辑）
5. 编辑器：`unity/Assets/AIFrameworkDemo/Editor/XXXSceneBuilder.cs`
6. 接线：`GenerateAllScenes` 加一行、`BootSceneBuilder` 加路径、`SceneVerifier` 加期望、EditMode 场景清单加一行
7. 跑五层验证 → 一次提交

**Meta 新切片**：`pwsh tools/new-slice.ps1 -Name XXX -Type Meta` → 填 `CONTRACT.md` → 实现 Handler/Presenter → 测试 → 五层验证。
